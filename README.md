# Textil Manager

Sistema de gestión para empresa textil.

## Stack
- React 18
- Supabase (base de datos)
- Vercel (hosting)

## Módulos
- Pedidos y pipeline de producción
- Productos con ficha técnica
- Telas y stock
- Proveedores
- Facturas de compra con IVA 22%
- Módulo IVA (CF / DB / Posición)
- Contactos

## Desarrollo local
```bash
npm install
npm start
```
